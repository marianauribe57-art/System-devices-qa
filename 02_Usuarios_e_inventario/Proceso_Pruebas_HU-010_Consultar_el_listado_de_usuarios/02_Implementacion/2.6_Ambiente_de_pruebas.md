# 2.6 Ambiente de pruebas · HU-010

**Fase:** Implementación
[Volver al flujo](../00_Flujo_metodologico.md)

> La guía EV05 no exige una instalación funcional de Device Systems. Este archivo deja definido **qué se necesitaría** para ejecutar y **qué impediría** hacerlo.

## Características

| Característica | Aplicación a HU-010 |
|---|---|
| Servidor compartido y distinto al del desarrollador | Ambiente de pruebas de Device Systems con la aplicación web y el servicio de consulta de usuarios · **por definir** |
| Nombres de dominio propios, no IP | La dirección del ambiente y del servicio de consulta **no está en la ficha**; se registra aquí cuando el equipo la conozca: `___` |
| Lo más parecido a producción | Misma versión de la aplicación y del servicio; datos ficticios de [2.3](2.3_Datos_de_prueba.md) en lugar de datos reales |
| Herramientas de incidencias y casos fuera del ambiente | Casos, scripts y resultados en este repositorio; incidencias en [4.1](../04_Evaluacion/4.1_Gestion_de_incidencias.md) y en issues de GitHub |

## Restricciones

- **Nunca** se usan datos reales ni producción: solo las 8 cuentas ficticias de [2.3](2.3_Datos_de_prueba.md).
- No se publican en el repositorio credenciales reales, identificaciones ni el Excel del grupo.
- El caso 014 agota el límite del minuto: se ejecuta **al final** y se espera **61 s** antes de cualquier otra consulta.
- No se inventa la dirección del servicio, los códigos de respuesta ni los textos de error: se registran tal como se observen.

## Condiciones que impedirían ejecutar

| Condición | Casos que quedarían **Bloqueados** |
|---|---|
| No hay un ambiente de pruebas de Device Systems | Todos (19 casos) |
| No es posible iniciar sesión con U-04 | 001–006, 009–019 |
| No se conoce la dirección del servicio de consulta | 008, 014, 015 |
| La base no coincide con el punto de control de 2.3 | 001–006, 009, 011–013, 019 |
| No se puede simular el fallo del servicio | 010 |
| No hay lector de pantalla disponible | 017 |

## Procedimientos de gestión

| Procedimiento | Cómo se aplica |
|---|---|

| Herramientas | Navegador, Postman y NVDA, según la tabla de recursos |
| Planificación de uso del ambiente | Orden de ejecución en 3.1; el caso 014 siempre al final |
