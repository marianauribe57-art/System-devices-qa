Los datos reemplazan expresiones como «un usuario activo» por valores concretos, para que cualquier persona pueda repetir la prueba. Todos son **ficticios**: el dominio `devsys.test` está reservado para pruebas y no corresponde a buzones reales. Las contraseñas son de prueba y solo existen en el ambiente de pruebas.
